# وَصلة · WASLA

**من احتياجـــك إلى فرصتـــك**

منصة رقمية ذكية ذات وجهين تربط أصحاب المشاريع الصغيرة والمتوسطة بمقدّمي الخدمات،
عبر تحليل المشروع بالذكاء الاصطناعي، وبناء خارطة طريق مخصّصة، ثم مطابقة الاحتياج بالقدرة.

> مشروع قيد التطوير · تحدي الجامعات ٢٠٢٦ · معسكر جدة

### عرضه في دقيقتين
1. **«تعبئة سريعة (لعرض التحكيم)»** — تعمل رحلة العميل كاملة.
2. رجوع ← **«ادخل كمقدّم خدمة»** ← **«تفعيل الاشتراك»** ← **«تعبئة سريعة»**.
3. في صندوق الفرص يظهر المشروع المحلَّل قبل قليل **بنفس نسبة المطابقة بالضبط**.

## 🔗 ما يميّز المشروع

الوجهان — العميل ومقدّم الخدمة — يستدعيان **نفس دالة المطابقة على نفس الكتالوج**:

| | |
|---|---|
| مقدّم خدمة يكمل ملفه | → يُضاف إلى الكتالوج الذي يراه أصحاب المشاريع |
| عميل يكمل رحلته | → يدخل مشروعه في صندوق فرص مقدّمي الخدمة |
| النسبة المئوية | **متطابقة في الاتجاهين — ٢٠٬٠٠٠ تجربة عشوائية، صفر اختلاف** |

## 🧠 أين الذكاء الاصطناعي

| الموضع | ماذا يفعل |
|---|---|
| **تصنيف الفكرة** | نص حر ← قطاع ونشاط فرعي بمطابقة كلمات موزونة |
| **متجه الاحتياج** | تسعة أبعاد من المرحلة والتحديات والهدف والميزانية والنشاط |

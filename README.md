# وَصلة · WASLA

**من احتياجـــك إلى فرصتـــك**

منصة رقمية ذكية ذات وجهين تربط أصحاب المشاريع الصغيرة والمتوسطة بمقدّمي الخدمات والجهات الداعمة،
عبر تحليل المشروع بالذكاء الاصطناعي، وبناء خارطة طريق مخصّصة، ثم مطابقة الاحتياج بالقدرة.

ملف واحد، بلا خادم وبلا إنترنت وبلا تثبيت.

### كيف تعرضه في دقيقتين

1. اضغط **«تعبئة سريعة (لعرض التحكيم)»** — تعمل رحلة العميل كاملة.
2. ارجع للبداية ← **«ادخل كمقدّم خدمة»** ← **«تفعيل الاشتراك»** ← **«تعبئة سريعة»**.
3. في صندوق الفرص سترى المشروع الذي حُلّل قبل قليل **بنفس نسبة المطابقة بالضبط**.

## 🔗 لماذا هذا المشروع مختلف

الوجهان — العميل ومقدّم الخدمة — يستدعيان **نفس دالة المطابقة على نفس الكتالوج**.
ليست واجهتين منفصلتين تبدوان متشابهتين، بل محرك واحد يُقرأ من الاتجاهين:

| | |
|---|---|
| مقدّم خدمة يكمل ملفه | → يُضاف إلى الكتالوج الذي يراه أصحاب المشاريع في توصياتهم |
| عميل يكمل رحلته | → يدخل مشروعه في صندوق فرص مقدّمي الخدمة |
| النسبة المئوية | **متطابقة في الاتجاهين — ٢٠٬٠٠٠ تجربة عشوائية، صفر اختلاف** |

## 🧠 أين الذكاء الاصطناعي فعلياً

| الموضع | ماذا يفعل |
|---|---|
| **تصنيف الفكرة** | يحوّل نصاً حراً إلى قطاع ونشاط فرعي بمطابقة كلمات موزونة |
| **بناء متجه الاحتياج** | تسعة أبعاد تُحسب من المرحلة والتحديات والهدف والميزانية والنشاط |
| **بناء خارطة الطريق** | اختيار وترتيب الخطوات بالأولوية والاعتمادية من مكتبة خطوات |
| **المطابقة** | تشابه جيبي بين متجهين، ثم ترجيح بالمرحلة ١٨٪ والقطاع ١٤٪ والمدينة ٨٪ |

لو حُذف الذكاء الاصطناعي لما بقي منتج — يبقى دليل جهات، وهو موجود أصلاً ولا أحد يستخدمه.
